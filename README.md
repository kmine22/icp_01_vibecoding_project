# Study Planner for GitHub Pages

This edition runs in your browser. Save links and upload images to add thumbnails to moodboard cards. Your planner data stays in the current browser.

The Python edition and local setup instructions are on the `main` branch.

## Update history

### Unreleased

- Single-day events and tasks use the color of their first tag. The shared tag editor has a themed dropdown and roomier color chips, and Untagged has a white swatch.
- Deleting a tag now opens a confirmation that shows how many tasks and events use it.
- Added a browser-only edition for GitHub Pages that supports saved links and uploaded images.

### v2.15

- Tasks and events share multiple tags, the same tag editor, and the Tags view.
- Filter the calendar and task list by tag, including untagged items.

### v2.14

- Multi-day events start below the date numbers and continue across week boundaries. Calendar cells use the fourth row for an overflow count when needed.
- Monthly receipts group moodboard saves by board and chart completed events by tag. Set a tag and mark completion in the event editor.
- Reorder moodboards by dragging their tabs or using Move left and Move right. Add board and Add scrap now share the same hover animation.

### v2.13

- Export the month on your calendar as a printable-style receipt with tasks, events, and moodboard activity.
