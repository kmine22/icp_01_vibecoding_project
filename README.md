# icp_01_vibecoding_project

Study Planner is a monthly calendar with drag-and-drop task scheduling and a moodboard for notes, images, and links. Tasks and scraps are saved in your browser.

## Run locally

From the repository root, run `python3 server.py` and open <http://127.0.0.1:8000>. No third-party Python packages are required. Link previews use your internet connection to read public pages.
